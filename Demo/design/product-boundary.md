# Nova Context 功能边界

本轮起以“本机 AI 开发项目工作台”为产品定位。核心结果：切换项目后，能找到关键文件、确认环境来源、管理凭证关联，并生成有依据的项目说明。

## 保留并深挖

1. 项目卡片与多项目切换：目录、运行环境、ENV / 后端关联、最近打开。
2. 文件目录浏览、搜索、常用文件、阅读与纯文本编辑，显式保存和冲突保护。
3. 本机环境说明与钥匙串凭证关联；密钥访问保持显式授权。
4. 明确范围、来源与检查时间的配置识别，以及主动导出的 AI 项目说明。
5. 大目录响应、配置持久化、错误恢复和真实使用流程验收。

## 冻结扩展

不新增聊天、模型调用、终端、命令执行、远程部署、SSH 客户端、云端账号/同步、团队协作或完整 IDE 功能。不扩充文档转换格式，不将已有转换功能作为主导航。不自动注入凭证到 AI 进程，不自动改写源码中的项目规则、ENV 或运行配置。

## 本轮交付

- 在后台检查项目根目录中的有限配置文件，提供运行环境、ENV 变量名和关键文件入口的来源信息。
- 区分手填环境与检测结果；检测不等于验证运行成功，根目录识别不代表覆盖所有子项目。
- 配置检查结果标记时间；重新检查后提示配置来源变化。无实时监听时不得宣称持续有效。
- 从已检查的配置和当前项目凭证引用主动导出 Markdown 项目说明；不夹带源码、ENV 值、密码或 Token，不执行项目内容。
- 导出前重新读取根配置，避免无提示地复用旧检测结果。

## 验收边界

自动测试覆盖有界读取、路径/符号链接保护、脱敏、配置变化识别、项目隔离和导出。性能继续保持后台索引与每页 200 行。实机验收必须另记证据；未执行的 OCR/钥匙串测试不得列为通过。

## 本机授权服务范围调整（用户后续确认）

已授权在本机为 AI 提供可到期、可作废的临时授权。首版仅 GitHub 读取当前账户，Unix socket + Python 客户端；从钥匙串取原始 Key 仅用于固定 HTTPS 请求认证头，不返回原始密钥、不接任意 URL、不传项目内容。此为凭证库的受限服务，不改变聊天/终端/SSH/远程部署的冻结边界。移除项目先作废其全部授权，保留文件与原始凭证。
