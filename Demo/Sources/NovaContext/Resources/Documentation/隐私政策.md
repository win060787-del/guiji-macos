## 本机处理

归记 在你选择的文件夹中浏览、读取和编辑文件。项目卡片、运行环境、凭证元数据及授权摘要保存在应用自己的本机数据目录；Token 和密码存于 macOS 钥匙串，该应用创建的条目不启用钥匙串同步。SSH 私钥仅保存路径引用，不读取或复制私钥内容。

应用不提供开发者托管后台或应用账号，不含广告和分析 SDK，不将项目正文、ENV 值、密码或原始 Key 上传给开发者。

## 用户主动发起的外部请求

当前本机授权服务仅支持读取 GitHub 当前账户。你创建临时授权、启用服务并发起该操作后，应用从钥匙串取出所选 Key，作为认证信息请求 https://api.github.com/user；对调用方只返回 login、id、type。GitHub 会依据自己的条款和隐私政策处理请求。本应用不代替 GitHub 管理账户或 Key，也无法撤回已受理请求。

打开公司支持链接、发送支持邮件或将导出文件交给其他工具，由你主动发起，适用相应接收方的隐私政策。应用不自动把项目说明发送给任何 AI 模型服务。

## 临时授权与导出

临时授权 Token 是独立的敏感凭证。应用只在创建时显示，并只在自己的持久化记录中保存摘要；你可主动复制或导出授权文件。导出文件包含临时授权 Token，不能公开或提交到公共仓库。到期或作废限制后续使用，不能撤回已返回的数据。

AI 项目说明和环境说明只导出配置元数据、变量名与凭证引用，不包含原始 Key。你自行选择导出位置，存储位置的同步或第三方读取行为由你所用系统和工具控制。

## 权限

文件访问由你选择目录或文件。通知按需请求系统授权，用于到期及轮换提醒。本机授权服务默认关闭、仅本机可连接，退出 App 即停止。钥匙串查看或复制由你主动操作，原始凭证不会作为普通配置文本持久化。

## 保留与删除

应用本机记录保留到你删除相关记录或清理应用数据。移除项目卡片先作废其临时授权，保留项目源文件及原始钥匙串凭证。删除凭证会移除其应用元数据并请求删除对应应用拥有的钥匙串条目；若系统拒绝，会反馈错误。仅卸载 App 不保证删除钥匙串条目。已经导出的文件或复制给第三方的内容需自行删除。

## 支持信息

你主动发送的支持邮件可能包含邮箱、系统版本、复现步骤及附件，用于处理请求。请勿发送原始 Key、密码、临时授权文件或 SSH 私钥。隐私相关请求请联系上述邮箱。

## 变更

产品的数据处理方式变更时更新本政策，并在需要时重新取得相应授权。正式公开的政策 URL 以 App Store 产品页所列链接为准。
