# 歸記 隱私政策

更新日期：2026 年 10 月 29 日
運營主體：NovaTech AI Limited
聯繫郵箱：developer@novatechai.xyz

## 本機處理

歸記 在你選擇的資料夾中瀏覽、讀取和編輯檔案。專案卡片、運行環境、憑證元數據及授權摘要保存在應用自己的本機數據目錄；Token 和密碼存於 macOS 鑰匙圈，該應用創建的條目不啓用鑰匙圈同步。SSH 私鑰僅保存路徑引用，不讀取或複製私鑰內容。

應用不提供開發者托管後台或應用賬號，不含廣告和分析 SDK，不將專案正文、ENV 值、密碼或原始 Key 上傳給開發者。

## 用戶主動發起的外部請求

當前本機授權服務僅支持讀取 GitHub 當前賬戶。你創建臨時授權、啓用服務併發起該操作後，應用從鑰匙圈取出所選 Key，作為認證信息請求 https://api.github.com/user；對調用方只返回 login、id、type。GitHub 會依據自己的條款和隱私政策處理請求。本應用不代替 GitHub 管理賬戶或 Key，也無法撤回已受理請求。

打開公司支持鏈接、發送支持郵件或將導出檔案交給其他工具，由你主動發起，適用相應接收方的隱私政策。應用不自動把專案說明發送給任何 AI 模型服務。

## 臨時授權與導出

臨時授權 Token 是獨立的敏感憑證。應用只在創建時顯示，並只在自己的持久化記錄中保存摘要；你可主動複製或導出授權檔案。導出檔案包含臨時授權 Token，不能公開或提交到公共倉庫。到期或作廢限制後續使用，不能撤回已返回的數據。

AI 專案說明和環境說明只導出設定元數據、變量名與憑證引用，不包含原始 Key。你自行選擇導出位置，存儲位置的同步或第三方讀取行為由你所用系統和工具控制。

## 權限

檔案訪問由你選擇目錄或檔案。通知按需請求系統授權，用於到期及輪換提醒。本機授權服務默認關閉、僅本機可連接，退出 App 即停止。鑰匙圈查看或複製由你主動操作，原始憑證不會作為普通設定文本持久化。

## 保留與刪除

應用本機記錄保留到你刪除相關記錄或清理應用數據。移除專案卡片先作廢其臨時授權，保留專案源檔案及原始鑰匙圈憑證。刪除憑證會移除其應用元數據並請求刪除對應應用擁有的鑰匙圈條目；若系統拒絕，會反饋錯誤。僅卸載 App 不保證刪除鑰匙圈條目。已經導出的檔案或複製給第三方的內容需自行刪除。

## 支持信息

你主動發送的支持郵件可能包含郵箱、系統版本、復現步驟及附件，用於處理請求。請勿發送原始 Key、密碼、臨時授權檔案或 SSH 私鑰。隱私相關請求請聯繫上述郵箱。

## 變更

產品的數據處理方式變更時更新本政策，並在需要時重新取得相應授權。正式公開的政策 URL 以 App Store 產品頁所列鏈接為準。
