# 歸記 使用手冊

把專案檔案、運行環境與憑證關聯整理在一個本機工作台里。無需註冊應用賬號；支持簡體中文、繁體中文、英語、西語、土耳其語和日語。支持 Apple Silicon Mac，macOS 14 或更新版本。

## 第一次使用

首次打開先選擇語言，再選擇專案、外觀和可選的憑證入口。語言默認跟隨本機支持的首選語言，無匹配時使用英語；可在“歸記 → 設定”或工具欄外觀菜單中隨時切換。切換語言不修改檔案正文、專案路徑和憑證值。可打開本機資料夾，也可體驗內置示例；取消檔案選擇不會導入任何目錄。選擇“稍後設定”直接進入專案空間。幫助菜單可隨時重新打開新手引導、使用手冊或示例專案。

外觀提供跟隨系統、淺色、深色。引導不會要求全盤訪問，不自動啓用本機授權服務，也不提前請求通知權限。

## 專案卡片

“添加專案”選擇資料夾。卡片顯示路徑、手填環境、已關聯的 ENV/API 變量和伺服器，以及設定檢查結果。打開卡片進入檔案樹；工具欄方格按鈕返回專案空間。

“設定”編輯專案名稱、開發/測試/生產環境、運行環境，或關聯已有憑證。“檢查根目錄設定”識別受支持檔案中的運行環境與 ENV 變量名；檢測結果和手填內容分別保留。

移除卡片前會確認，並先作廢該專案全部臨時授權。源檔案、專案設定和原始鑰匙圈憑證保留；仍可在本機服務中查看已移除專案的授權記錄。

## 檔案與編輯

側欄逐層展開資料夾，可搜索檔案名或路徑、篩選和排序。搜索覆蓋已載入檔案；達到索引上限時，展開子目錄可繼續分批載入。默認單批最多十萬檔案，列表每頁最多二百行；這不是單屏加載十萬行。

Markdown、JSON、YAML、TOML、TXT 及常用程式碼支持 UTF-8 純文本編輯，最大 2 MB。使用檔案工具欄的筆圖標或 ⌘E 切換閱讀/編輯，⌘S 保存。圖釘加入常用檔案。Markdown 編輯時可展開實時分欄預覽。

切換檔案、專案、關閉或退出時會檢查未保存更改。磁盤內容被外部修改時拒絕覆蓋，保留草稿。ENV 檔案保持脫敏只讀；只讀預覽隱藏常見敏感值，編輯模式讀取原始內容，請勿把原始密鑰粘貼到公共文檔。

## 設定檢查與 AI 專案說明

檢測只覆蓋根目錄的固定設定白名單，包括 package.json、.nvmrc、.python-version、pyproject.toml、go.mod 等。僅提取受限的版本信息，ENV 只提取變量名；不會執行腳本、讀取規則檔案正文或檢測遠程服務在線。單檔案最多 128 KiB，總讀取最多 1 MiB。不自動檢查子專案，也沒有實時設定監聽。

卡片菜單或工具欄“導出 AI 專案說明”生成 project-brief.md。導出前處理當前未保存編輯並重新檢查磁盤設定；選擇新檔案名。說明包含手填環境、來源檔案、檢查時間、關鍵檔案入口和當前專案憑證引用，不包含原始 Key 或臨時授權 Token。將檔案或路徑交給 AI 即可作為專案背景；設定改變後重新導出。

## API 與伺服器憑證

工具欄鑰匙入口打開憑證庫。API 憑證包含服務商、地址、環境變量名和 Token；伺服器設定包含地址、端口、用戶名、部署目錄以及密碼或 SSH 私鑰路徑。

Token/密碼保存在本機鑰匙圈，條目不啓用同步。SSH 模式僅保存路徑，不讀取或複製私鑰。編輯已有憑證時，密鑰留空保留原值；查看/複製必須主動操作。複製內容在約 45 秒後且剪貼板未被其他內容替換時清除。

同一憑證可關聯多個專案，解除關聯不刪除憑證；刪除憑證會確認。元數據存於應用本機目錄，不發送到公司後台。

## 日期與通知

憑證可設定到期日期、下次輪換日期及本機通知。添加日期表示錄入本應用的時間；舊數據未記錄時保持未知。到期日期由你按服務商資料填寫，應用不會自動查詢真實 Key 的有效期。

提醒可選提前 7、3、1 天及當天，默認 7/1/當天。開啓後由 macOS 請求通知授權；拒絕後可在系統設定的通知頁面調整。修改日期會替換舊計劃，刪除憑證會取消其計劃。

服務頁顯示通知授權狀態、排程數量和待補排數量。單次最多排入最近 48 條，啓動應用、修改憑證或“同步提醒”時補排。提醒受系統權限、專注模式等影響；長期不打開應用時，超出窗口的提醒不會自動無限補齊。

## 給 AI 臨時授權

當前只有 GitHub 只讀操作：讀取當前賬戶，並僅返回 login、id、type。不是任意 API 代理，不支持 SSH 執行或模型聊天。

1. 創建 API 憑證，可用“服務預設 → GitHub”填寫地址 https://api.github.com 和變量名；Token 來自你的 GitHub 賬戶。
2. 將該憑證關聯專案。打開卡片菜單“AI 臨時授權…”或工具欄伺服器入口。
3. 選中專案、憑證和有效天數，創建授權。支持 1–365 天，但不能晚於原憑證填寫的到期時間。
4. 複製臨時授權或導出 Agent 授權檔案。臨時 Token 只顯示一次，仍是敏感憑證，不要公開或提交 Git。關閉後需要重新生成才能再次取得。
5. 在本機服務頁啓動授權服務。選擇“Agent 客戶端 → 複製原生調用命令…”，選中已導出的授權檔案，把命令交給本機 Agent。內置原生入口無需額外安裝運行環境。

```sh
"/Applications/歸記.app/Contents/MacOS/Nova Context" --agent < "/path/to/nova-agent-grant.json"
```

授權檔案通過標準輸入讀取，Token 不放進命令參數。若選用“導出 Python 示例…”，該可選示例需自行準備 Python 3；它不是使用原生入口的前置條件。

原始 Key 不交給 AI；本機服務驗證臨時授權，再從鑰匙圈取 Key 調用固定 GitHub HTTPS 接口。授權檔案包含本機 socket 路徑、專案、固定操作和臨時 Token，0600 私有保存；不包含原始 Key。不安裝系統後台服務、不開放局域網端口，App 關閉後服務停止。

到期、作廢、重新生成、原憑證變更/到期/刪除或解除專案關聯後，後續調用被拒絕。作廢無法收回已受理的外部請求或已返回數據。“全部作廢”只影響選定專案。服務最多四路同時執行，超額請求可能被拒絕；最近 128 個請求 ID 內重復請求被拒絕。

## 文檔預覽與轉換

PDF、圖片可在內容區預覽。工作區菜單或檔案右鍵可按需轉換 PDF、DOCX、XLSX、PPTX、圖片為 Markdown，保留源檔案，預覽後另存新檔案。舊 DOC/XLS/PPT 不支持；轉換源檔案最多 50 MB。PDF 最多四十頁，圖片僅第一幀，複雜版式、圖表、公式及掃描內容可能不完整。

當前機器上 Vision/OCR 的兩個自動化用例仍有系統環境問題；掃描 PDF 和圖片 OCR 不作為已驗收的商店核心功能宣傳。優先使用有文字層的 PDF 和現代 Office 檔案。

## 常見問題

- 沒找到檔案：清除搜索/篩選，檢查當前位置與是否仍在分批索引，再刷新。符號鏈接、私鑰及構建緩存會跳過。
- 無法編輯：檢查是否為支持的 UTF-8 文本、是否超過 2 MB；ENV、PDF、圖片和 Office 不是普通文本編輯入口。
- 授權無效：確認服務已啓動、專案匹配、憑證仍關聯且未到期；憑證變更後重新生成授權。
- 客戶端提示 insecureGrantFile：使用 App 導出的原始私有檔案，不要將其改為所有人可讀。
- 真實接口失敗：確認 GitHub Token 在服務商側仍有效且權限足夠；應用不顯示上游原始錯誤，避免洩露憑證。
- 無通知：檢查憑證通知開關、提醒時間、系統授權與服務頁排程狀態。

## 數據與支持

專案檔案留在你選擇的目錄；應用設定、專案庫和憑證元數據位於應用的 Application Support/NovaContextDemo 目錄；原始密鑰位於鑰匙圈。導出檔案由你選定位置保存。

應用不含開發者托管後台、廣告或分析 SDK。只有你啓用授權服務併發起指定操作時，本機會帶認證信息請求 GitHub；GitHub 按其政策處理請求。不會把專案檔案或上下文發送給模型提供商。

支持郵箱：developer@novatechai.xyz。反饋請附應用版本、系統版本、操作步驟及已脫敏截圖，不要發送 Token、密碼、授權檔案或 SSH 私鑰。
