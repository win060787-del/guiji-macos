# 归记 使用手册

把项目文件、运行环境与凭证关联整理在一个本机工作台里。无需注册应用账号；支持简体中文、繁体中文、英语、西语、土耳其语和日语。支持 Apple Silicon Mac，macOS 14 或更新版本。

## 第一次使用

首次打开先选择语言，再选择项目、外观和可选的凭证入口。语言默认跟随本机支持的首选语言，无匹配时使用英语；可在“归记 → 设置”或工具栏外观菜单中随时切换。切换语言不修改文件正文、项目路径和凭证值。可打开本机文件夹，也可体验内置示例；取消文件选择不会导入任何目录。选择“稍后设置”直接进入项目空间。帮助菜单可随时重新打开新手引导、使用手册或示例项目。

外观提供跟随系统、浅色、深色。引导不会要求全盘访问，不自动启用本机授权服务，也不提前请求通知权限。

## 项目卡片

“添加项目”选择文件夹。卡片显示路径、手填环境、已关联的 ENV/API 变量和服务器，以及配置检查结果。打开卡片进入文件树；工具栏方格按钮返回项目空间。

“配置”编辑项目名称、开发/测试/生产环境、运行环境，或关联已有凭证。“检查根目录配置”识别受支持文件中的运行环境与 ENV 变量名；检测结果和手填内容分别保留。

移除卡片前会确认，并先作废该项目全部临时授权。源文件、项目设置和原始钥匙串凭证保留；仍可在本机服务中查看已移除项目的授权记录。

## 文件与编辑

侧栏逐层展开文件夹，可搜索文件名或路径、筛选和排序。搜索覆盖已载入文件；达到索引上限时，展开子目录可继续分批载入。默认单批最多十万文件，列表每页最多二百行；这不是单屏加载十万行。

Markdown、JSON、YAML、TOML、TXT 及常用代码支持 UTF-8 纯文本编辑，最大 2 MB。使用文件工具栏的笔图标或 ⌘E 切换阅读/编辑，⌘S 保存。图钉加入常用文件。Markdown 编辑时可展开实时分栏预览。

切换文件、项目、关闭或退出时会检查未保存更改。磁盘内容被外部修改时拒绝覆盖，保留草稿。ENV 文件保持脱敏只读；只读预览隐藏常见敏感值，编辑模式读取原始内容，请勿把原始密钥粘贴到公共文档。

## 配置检查与 AI 项目说明

检测只覆盖根目录的固定配置白名单，包括 package.json、.nvmrc、.python-version、pyproject.toml、go.mod 等。仅提取受限的版本信息，ENV 只提取变量名；不会执行脚本、读取规则文件正文或检测远程服务在线。单文件最多 128 KiB，总读取最多 1 MiB。不自动检查子项目，也没有实时配置监听。

卡片菜单或工具栏“导出 AI 项目说明”生成 project-brief.md。导出前处理当前未保存编辑并重新检查磁盘配置；选择新文件名。说明包含手填环境、来源文件、检查时间、关键文件入口和当前项目凭证引用，不包含原始 Key 或临时授权 Token。将文件或路径交给 AI 即可作为项目背景；配置改变后重新导出。

## API 与服务器凭证

工具栏钥匙入口打开凭证库。API 凭证包含服务商、地址、环境变量名和 Token；服务器配置包含地址、端口、用户名、部署目录以及密码或 SSH 私钥路径。

Token/密码保存在本机钥匙串，条目不启用同步。SSH 模式仅保存路径，不读取或复制私钥。编辑已有凭证时，密钥留空保留原值；查看/复制必须主动操作。复制内容在约 45 秒后且剪贴板未被其他内容替换时清除。

同一凭证可关联多个项目，解除关联不删除凭证；删除凭证会确认。元数据存于应用本机目录，不发送到公司后台。

## 日期与通知

凭证可设置到期日期、下次轮换日期及本机通知。添加日期表示录入本应用的时间；旧数据未记录时保持未知。到期日期由你按服务商资料填写，应用不会自动查询真实 Key 的有效期。

提醒可选提前 7、3、1 天及当天，默认 7/1/当天。开启后由 macOS 请求通知授权；拒绝后可在系统设置的通知页面调整。修改日期会替换旧计划，删除凭证会取消其计划。

服务页显示通知授权状态、排程数量和待补排数量。单次最多排入最近 48 条，启动应用、修改凭证或“同步提醒”时补排。提醒受系统权限、专注模式等影响；长期不打开应用时，超出窗口的提醒不会自动无限补齐。

## 给 AI 临时授权

当前只有 GitHub 只读操作：读取当前账户，并仅返回 login、id、type。不是任意 API 代理，不支持 SSH 执行或模型聊天。

1. 创建 API 凭证，可用“服务预设 → GitHub”填写地址 https://api.github.com 和变量名；Token 来自你的 GitHub 账户。
2. 将该凭证关联项目。打开卡片菜单“AI 临时授权…”或工具栏服务器入口。
3. 选中项目、凭证和有效天数，创建授权。支持 1–365 天，但不能晚于原凭证填写的到期时间。
4. 复制临时授权或导出 Agent 授权文件。临时 Token 只显示一次，仍是敏感凭证，不要公开或提交 Git。关闭后需要重新生成才能再次取得。
5. 在本机服务页启动授权服务。选择“Agent 客户端 → 复制原生调用命令…”，选中已导出的授权文件，把命令交给本机 Agent。内置原生入口无需额外安装运行环境。

```sh
"/Applications/归记.app/Contents/MacOS/Nova Context" --agent < "/path/to/nova-agent-grant.json"
```

授权文件通过标准输入读取，Token 不放进命令参数。若选用“导出 Python 示例…”，该可选示例需自行准备 Python 3；它不是使用原生入口的前置条件。

原始 Key 不交给 AI；本机服务验证临时授权，再从钥匙串取 Key 调用固定 GitHub HTTPS 接口。授权文件包含本机 socket 路径、项目、固定操作和临时 Token，0600 私有保存；不包含原始 Key。不安装系统后台服务、不开放局域网端口，App 关闭后服务停止。

到期、作废、重新生成、原凭证变更/到期/删除或解除项目关联后，后续调用被拒绝。作废无法收回已受理的外部请求或已返回数据。“全部作废”只影响选定项目。服务最多四路同时执行，超额请求可能被拒绝；最近 128 个请求 ID 内重复请求被拒绝。

## 文档预览与转换

PDF、图片可在内容区预览。工作区菜单或文件右键可按需转换 PDF、DOCX、XLSX、PPTX、图片为 Markdown，保留源文件，预览后另存新文件。旧 DOC/XLS/PPT 不支持；转换源文件最多 50 MB。PDF 最多四十页，图片仅第一帧，复杂版式、图表、公式及扫描内容可能不完整。

当前机器上 Vision/OCR 的两个自动化用例仍有系统环境问题；扫描 PDF 和图片 OCR 不作为已验收的商店核心功能宣传。优先使用有文字层的 PDF 和现代 Office 文件。

## 常见问题

- 没找到文件：清除搜索/筛选，检查当前位置与是否仍在分批索引，再刷新。符号链接、私钥及构建缓存会跳过。
- 无法编辑：检查是否为支持的 UTF-8 文本、是否超过 2 MB；ENV、PDF、图片和 Office 不是普通文本编辑入口。
- 授权无效：确认服务已启动、项目匹配、凭证仍关联且未到期；凭证变更后重新生成授权。
- 客户端提示 insecureGrantFile：使用 App 导出的原始私有文件，不要将其改为所有人可读。
- 真实接口失败：确认 GitHub Token 在服务商侧仍有效且权限足够；应用不显示上游原始错误，避免泄露凭证。
- 无通知：检查凭证通知开关、提醒时间、系统授权与服务页排程状态。

## 数据与支持

项目文件留在你选择的目录；应用设置、项目库和凭证元数据位于应用的 Application Support/NovaContextDemo 目录；原始密钥位于钥匙串。导出文件由你选定位置保存。

应用不含开发者托管后台、广告或分析 SDK。只有你启用授权服务并发起指定操作时，本机会带认证信息请求 GitHub；GitHub 按其政策处理请求。不会把项目文件或上下文发送给模型提供商。

支持邮箱：developer@novatechai.xyz。反馈请附应用版本、系统版本、操作步骤及已脱敏截图，不要发送 Token、密码、授权文件或 SSH 私钥。
