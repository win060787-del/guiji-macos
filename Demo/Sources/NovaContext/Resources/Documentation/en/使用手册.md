# Guiji User Guide

Guiji is a local workspace for project files, configuration and credentials. No app account is required. Requires Apple Silicon and macOS 14 or later.

## Language and first launch
Choose your language before selecting a project and appearance. System matches your Mac’s supported preferred language, falling back to English. Change it anytime in Guiji → Settings or the toolbar appearance menu. Available: Simplified Chinese, Traditional Chinese, English, Spanish, Turkish and Japanese. Switching does not translate file contents or change credential values. You can skip setup or reopen it from Help. No full-disk permission is requested.

## Projects and files
Add a local folder to create a project card. Cards show paths, manually entered runtime, linked ENV/API credentials, server settings and inspection results. Open a card to browse nested folders; use the grid button to return to projects. Search names and paths, filter by date or format, sort and pin frequent files. Search covers loaded entries; expand subfolders to load more. Indexing is batched, up to 100,000 files per batch, with 200 visible rows per page. Removing a card confirms first and revokes its temporary grants; original files, project settings and Keychain credentials remain.

## Editing and conversion
Use the pen button or Command-E to switch reading/editing. Command-S saves UTF-8 Markdown, JSON, YAML, TOML, text and common source files up to 2 MB. Markdown supports split preview and a focused main view. Changing files, projects or quitting checks unsaved changes. External modifications block overwriting and preserve your draft. ENV stays masked and read-only; ordinary editing uses original content. Keep backups and never paste secrets into public documents. Import PDF, Office (.docx/.xlsx/.pptx) or images to convert locally to Markdown. Save under a new filename; check OCR, tables, formulas and layout against the original.

## Configuration and AI briefs
Inspect supported root files such as package.json, .nvmrc, .python-version, pyproject.toml and go.mod. This extracts limited version information and ENV names, without executing scripts, scanning subprojects or verifying remote services. Limits: 128 KiB per file, 1 MiB total. Export AI project brief rechecks configuration and includes sources, timestamps, entry files, manual environment and credential references, never original keys or temporary tokens. Give the exported file to your AI tool yourself; regenerate after changes.

## Credentials and reminders
Open the key toolbar button for API tokens and server configuration. Passwords/tokens stay in app-owned local Keychain entries without sync. SSH mode stores the key path only; it neither reads private-key contents nor executes SSH. Blank secret fields preserve existing values. Reveal/copy are explicit; copied secrets clear after about 45 seconds if the clipboard has not changed. Link one credential to multiple projects; unlinking does not delete it.
Expiry/rotation dates are entered manually, not verified with providers. Reminders can run 7, 3, 1 days before or on the day, with macOS permission. Up to 48 pending reminders are scheduled each sync, refreshed at launch, credential changes or manual sync. System permissions and Focus affect delivery. Long periods without opening the app can leave later reminders unscheduled.

## Temporary AI grants
Currently supports only GitHub read-current-account, returning login, id and type. Create an API credential using the GitHub preset, link it to a project, then create a grant for 1–365 days, no later than the recorded credential expiry. Copy/export the temporary token when shown once; treat it as a secret and keep it out of Git. Start Local Service, then choose Agent Client → Copy native invocation command and select the exported grant file. The native --agent entry point reads it from standard input and needs no extra runtime. The optional Python example requires Python 3. Stop the service, revoke or regenerate grants when done. Revocation blocks future requests; accepted requests and returned data cannot be recalled. This is not AI chat, an arbitrary API proxy or remote deployment.

## Recovery and support
Reselect a moved or inaccessible folder to restore permission. If settings cannot be read, originals are preserved; avoid replacing them until recovered. Delete credentials explicitly before uninstalling if required, since uninstalling alone may leave Keychain entries. Contact developer@novatechai.xyz without sending secrets or grant files.
