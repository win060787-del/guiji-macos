# Orbit 产品需求

## 目标

帮助小型团队将任务分配、当前进展和交付记录放在同一个工作台。

## 首个版本

### 邮箱登录

用户输入邮箱，点击发送登录链接。页面应校验格式、防止重复提交，并给出明确的成功或失败提示。

### 任务看板

| 状态 | 用户动作 | 预期行为 |
| --- | --- | --- |
| 待开始 | 创建任务 | 标题必填，可指定负责人 |
| 进行中 | 开始任务 | 记录开始时间 |
| 已完成 | 完成任务 | 保留交付说明 |

## 验收标准

- [ ] 邮箱输入可通过键盘操作。
- [ ] 请求进行时按钮显示加载状态。
- [ ] 失败时可重新提交。
- [ ] 不在页面或日志中显示凭证。
